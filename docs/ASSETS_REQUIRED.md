# Assets Required

**Nothing here is required for the app to build or run.** Every theme is fully usable today with pure CSS/SVG effects
(rings, bolts, crescents, webs…). The files below are *optional upgrades* you can add if you have the right to use the artwork.

> **Copyright:** HisaabKitaab ships **no** Marvel/DC images, logos or character art. Only add artwork you created, bought, or
> are licensed to use. For a college demo, original abstract art (textures, gradients, silhouettes you drew yourself) is safest.

## How it works

1. Placeholders already exist at `public/assets/themes/<theme>/<theme>_background_PLACEHOLDER.png` and `<theme>_icon_PLACEHOLDER.png`.
   **The app never loads `*_PLACEHOLDER.png` files.**
2. To activate real art, save your file in the same folder with the name **without** `_PLACEHOLDER`, e.g.
   `public/assets/themes/iron_man/iron_man_background.png`.
3. Refresh. The background appears behind the page (only for themes with a background effect layer: all 12 hero themes), and the icon
   appears next to the theme name in the Theme Gallery. If a file is missing the app silently skips it - nothing breaks.
4. Tips: keep backgrounds dark/low-contrast so text stays readable, and under ~300 KB (use WebP-to-PNG or compress) for mobile speed.

## App / PWA icons (in `public/icons/`)

Default icons were generated by `python3 scripts/gen-icons.py` (an original two-ring "shared bill" mark). Replace them with your own
branding by overwriting these files (keep the names and sizes):

| Purpose | Exact filename | Format | Dimensions | Transparency | Required? |
|---|---|---|---|---|---|
| Install icon | `public/icons/icon-192.png` | PNG | 192 x 192 | Allowed (rounded corners) | Yes (defaults provided) |
| Install icon (large) | `public/icons/icon-512.png` | PNG | 512 x 512 | Allowed | Yes (defaults provided) |
| Android adaptive/maskable | `public/icons/maskable-512.png` | PNG | 512 x 512 | **No** - full-bleed; keep logo inside the centre 80% | Yes (defaults provided) |
| iOS home-screen | `public/icons/apple-touch-icon.png` | PNG | 180 x 180 | **No** - iOS rounds it | Yes (defaults provided) |
| Browser tab icon | `app/icon.png` | PNG | 256 x 256 | Allowed | Yes (default provided) |

## Other placeholder folders

`public/assets/icons/`, `public/assets/backgrounds/` and `public/assets/animations/` each contain one placeholder and are reserved for future
shared artwork. They are not referenced by the current UI.
